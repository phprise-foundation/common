# PHPRise Common

This is an [Assembly Repository](PHILOSOPHY.md#2-assembly-repositories-the-assembly) based on the [OTAKU Manifesto](PHILOSOPHY.md).

This repository connects the [Contracts](https://github.com/phprise-foundation/common-contract) and the [Value Objects](https://github.com/phprise-foundation/common-value-object).

## Installation

```bash
composer require phprise/common
```

## Usage

See the [Contracts](https://github.com/phprise-foundation/common-contract) and the [Value Objects](https://github.com/phprise-foundation/common-value-object) repositories for more information.
